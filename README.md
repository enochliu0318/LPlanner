# 备课本 · Lesson Notebook

面向英语老师的轻量备课/教案编辑网站。可以在网页上按结构化模板填写教案，
一键导出 **PDF** 或 **Word（.docx）**，数据保存在你自己的浏览器中，
**全程零成本、无需注册登录**。

---

## 一、功能说明

- **教案列表（首页 index.html）**：查看、搜索、复制、删除已保存的教案。
- **教案编辑（editor.html）**：对应你提供模板中的两张表——
  「授课教案」基本信息 + 「讲稿部分（教学内容及过程）」，
  支持：
  - 基本信息（课程名称/类别/教师/时间/课题/学时）
  - 教学目标与要求
  - 参考资料（可添加多条，标签 + 链接）
  - 教学内容及过程（多级要点列表，可上移/下移/切换层级）
  - 备注、作业布置、课后小结
- **导出 PDF**：点击"导出 PDF"会生成一个还原模板排版的打印视图，
  随后调用浏览器的打印功能，在弹出的打印对话框中选择"另存为 PDF"即可。
- **导出 Word**：点击"导出 Word"会在浏览器端直接生成 .docx 文件并下载，
  首次导出需要联网加载一次开源组件（约几百 KB），之后同一浏览器会话内无需重复加载。
- **备份 / 迁移**：首页的"导出备份"会把所有教案打包成一个 JSON 文件下载；
  "导入备份"可以把 JSON 文件中的教案合并或恢复到当前浏览器。
  **建议定期导出备份**，因为数据只存在本机浏览器里，清除浏览器数据会导致教案丢失。

## 二、数据存储说明（务必了解）

本网站**没有后端服务器和数据库**，所有教案数据保存在浏览器的
`localStorage` 中，具体来说：

- 数据只属于"这一台电脑 + 这一个浏览器"，换设备或换浏览器看不到之前的教案；
- 如果清除浏览器缓存/网站数据，教案会丢失；
- 因此强烈建议：**每次备课完成后，点一下"导出备份"**，把 JSON 文件保存到
  你自己的网盘或本地文件夹里，需要时可以"导入备份"恢复。

如果未来你希望多设备同步或多位老师共享数据，需要引入云端存储
（例如 Cloudflare D1 数据库 + 一个简单的访问口令），这部分我可以在你需要时再补充，
目前的免费方案不含这部分是为了严格贯彻"零成本、无需登录"的要求。

## 三、本地预览

由于页面使用了 ES Module（`<script type="module">`），直接双击 `index.html`
在部分浏览器中可能因跨域限制无法正常加载 JS，建议用一个本地静态服务器预览：

```bash
# 任选一种方式，在 lesson-planner 目录下执行
python3 -m http.server 8000
# 或者，如果你安装了 Node.js
npx serve .
```

然后浏览器打开 `http://localhost:8000` 即可。

## 四、部署到 Cloudflare Pages（你已有域名）

### 方式一：直接上传（最简单，适合先跑起来看看效果）

1. 登录 Cloudflare 控制台 → 左侧菜单 **Workers & Pages** → **创建应用程序** →
   选择 **Pages** → **上传资产（Upload assets）**。
2. 项目名称随意填写（例如 `lesson-notebook`）。
3. 把本项目**整个 `lesson-planner` 文件夹里的内容**（不是外层文件夹本身）
   拖拽上传，Cloudflare 会自动识别 `index.html` 作为首页。
4. 部署完成后，Cloudflare 会分配一个 `xxx.pages.dev` 的默认域名，可直接访问。
5. 进入该 Pages 项目 → **自定义域** → 添加你自己的域名（或子域名，
   例如 `lesson.你的域名.com`），按提示添加 DNS 记录（如果域名本来就在
   Cloudflare 上，一般是自动配置，几分钟内生效）。

### 方式二：连接 Git 仓库（推荐，便于以后持续更新）

1. 把本项目推送到 GitHub/GitLab 仓库。
2. Cloudflare 控制台 → **Workers & Pages** → 创建应用程序 → **Pages** →
   **连接到 Git**，选择你的仓库。
3. 构建设置：
   - **框架预设**：无（None）/ 静态站点
   - **构建命令**：留空
   - **构建输出目录**：`/`（如果 `lesson-planner` 是仓库根目录）或
     `lesson-planner`（如果它是仓库中的子目录）
4. 保存并部署，之后每次你 `git push`，Cloudflare 会自动重新部署。
5. 同上，在项目设置里绑定你自己的域名。

整个过程不涉及任何付费项：Cloudflare Pages 静态托管、自定义域名绑定均在免费额度内。

## 五、后续可扩展方向（AI 功能占位）

编辑页面底部预留了一个"AI 辅助备课"的占位区块（`.ai-placeholder`）。
等你想清楚具体需求后（例如：根据课题自动生成教学内容初稿 / 对已写内容做语法润色），
可以选择：

- **按次付费调用 API**（如接入某家大模型的 API Key），成本可控、效果最好，
  但严格意义上不是"免费"，需要你自己申请密钥并承担调用费用；
- **使用某些平台的免费额度**，适合调用量不大的个人使用场景；
- **前端直接调用免费公开的开源模型推理服务**，效果和稳定性通常不如商用模型。

到时候我可以根据你的具体需求（生成什么内容、调用频率、预算）帮你设计合适的接入方式。
